Computer Malware


What is computer malware?

computer_malware.sh

Malware, short for "Malicious Software", refers to any software, code, or computer program designed to harm a computer system or its user. Malware isn't just one thing, it is an entire category of digital threats.


The most common types of computer malware:

  • Viruses
  • Trojan Horses
  • Worms

What does malware target:

User Data

Malware attempts to steal users sensitvie information such as passwords and emails.

Operating System Files

Malware will target boot files to ensure the malware starts, spreads, and makes it difficult to remove

Resources

Malware can use users computer prower for its own gain, such as computing botnets or cryptomining.
