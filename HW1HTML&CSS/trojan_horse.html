Trojan Horses


FILE:FreeGame_Installer.exe

ACTUAL TYPE:Trojan_remote_access

Trojans don't replicate like viruses and worms. Instead they wait for the user to execute the malicious file and open a back door for the attacker to gain access.


Trojan Charateristics:

Backdoor Access

Allows for hacker to deliver various kinds of malware or access users computer itself.

Disguised Gift

Trojans appear as benefical to the user, such as a free game or security update to trick user into executing the malware.

Lack of Replication

Unlike how a virus copies itself, and worms spread, Trojans don't replicate. They spread only when people share the infected file through emails, download links, and USB drives.

Stay Hidden

Trojans often rename itself to look legit and stay hidden on the system as long as possible. Sometime modifiying system registry to change the name automatically on system start up.
